# 习惯打卡 Habit Tracker

一个纯静态的单页应用：记录每天的习惯打卡，查看月历热力图和连续打卡统计。

**无框架、无依赖、无构建步骤、无后端**，全部数据保存在浏览器的 `localStorage` 中，换台设备用「导出 / 导入 JSON」即可迁移。

## 功能

- **多个习惯**：新建、编辑（名称 / 颜色标记）、删除；首次打开自动内置 3 个示例习惯
- **每日打卡**：卡片上一键打卡 / 取消，也可以在月历上点击过去或当天的任意日期补打卡
- **月历热力图**：每个习惯一张当月日历，打卡过的日期以习惯颜色高亮，支持前后翻月
- **统计**：当前连续天数、最长连续天数、累计打卡次数、今日完成进度（x/y 进度条）
- **数据备份**：一键导出 JSON（复制到剪贴板或下载 `.json` 文件），支持粘贴或选文件导入覆盖

## 快速开始

方式一：直接双击打开 `index.html` 即可使用。

方式二（推荐）：起一个本地静态服务：

```bash
cd habit-tracker
python3 -m http.server 8021
# 浏览器访问 http://127.0.0.1:8021
```

> 首次打开会自动创建 3 个示例习惯（喝水、阅读、运动），并附带最近 6 周的演示打卡记录，
> 用于展示热力图和连续天数效果；今天的日期特意留空，可以立刻体验打卡。不想要示例数据的话，
> 把 3 个示例习惯删掉即可。

## 使用说明

1. **打卡**：点击习惯卡片上的「打卡」按钮，按钮变为「✓ 今日已打卡」，今日进度条同步更新。
2. **补打卡 / 取消**：在月历上直接点击某一天即可切换该天是否打卡（未来日期不可点）。
3. **新建习惯**：右上角「＋ 新建习惯」，填写名称、选一个颜色标记后保存。
4. **编辑 / 删除**：每张卡片右上角的编辑、删除按钮（删除有确认弹窗，会连同打卡记录一起删除）。
5. **导出**：右上角「📤 导出」→ 复制文本或下载 `.json` 文件。
6. **导入**：右上角「📥 导入」→ 选择备份文件或粘贴 JSON → 「导入并覆盖」。⚠️ 导入会覆盖当前全部数据。

## 数据格式

存储位置：`localStorage`，键名 `habit-tracker:v1`。

```json
{
  "habits": [
    { "id": "0f2c…", "name": "喝水 8 杯", "color": "#4f6ef7", "createdAt": "2026-10-24" }
  ],
  "checkins": {
    "0f2c…": ["2026-10-22", "2026-10-23", "2026-10-24"]
  }
}
```

- 日期一律使用本地时区的 `YYYY-MM-DD` 字符串
- 导入时会自动过滤非法数据（未知字段、坏日期、重复 id 等），所以手工整理过的备份也能安全导入

## 常见问题

- **数据存在哪里？会不会上传？** 只存在本机浏览器的 localStorage 里，没有任何网络请求。
- **想彻底清空？** 删除全部习惯，或在浏览器开发者工具 → Application → Local Storage 中删除键 `habit-tracker:v1` 后刷新。
- **换浏览器 / 换电脑数据还在吗？** 不在。请先「导出」JSON，在新设备上「导入」。
- **连续天数怎么算？** 今天已打卡则从今天往前连续计算；今天还没打卡则从昨天往前算（当天打卡不会让连续中断显示为 0）。

## 兼容性

需要支持 `localStorage`、`aspect-ratio`、`crypto.randomUUID` 的现代浏览器（Chrome / Edge 96+、Firefox 96+、Safari 15.4+ 等）。
